Phase 3 surface-target test
  1. Choose entry mode for a large scene or surface mode for a prop/diorama.
  2. Load an asset, then select START AR.
  3. Move the device slowly while it scans nearby surfaces.
  4. A green ring means a valid surface target.
  5. An amber ring means an established target was temporarily lost.
  6. In surface mode, select the green target to place the asset. A blue flash confirms placement.
  7. Fit-volume and custom scaling are explicit and do not alter importer normalization.
